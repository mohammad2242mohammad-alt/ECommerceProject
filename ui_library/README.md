# E-Commerce UI Library

این شاخه برای ساخت و نگهداری کتابخانه رابط کاربری فروشگاه است.

اصل کار: **هر ابزار و هر بخش یک‌بار ساخته شود؛ صفحه‌ها فقط آن‌ها را با ترتیب‌های مختلف کنار هم بچینند.**

## قواعد
- تغییر طراحی یک صفحه نباید باعث بازنویسی Componentهای دیگر شود.
- Componentها مستقل و قابل استفاده مجدد باشند.
- ترتیب Sectionها از Layout جدا باشد.
- منطق کسب‌وکار Laravel و API اصلی پروژه دست‌کاری نمی‌شود.
- این شاخه فعلاً اسکلت UI است و مرحله‌به‌مرحله به `mobile/lib` متصل می‌شود.

## چیدمان قابل تنظیم Home
ترتیب Home داخل فایل‌های JSON در `layout_configs/` نگهداری می‌شود. صفحه فقط شناسه فایل را می‌گیرد:

```dart
const HomeScreen(layoutConfig: 'home_default');
```

یا برای چیدمان دیگر:

```dart
const HomeScreen(layoutConfig: 'home_offers_first');
```

در نتیجه برای جابه‌جایی بخش‌ها نیازی به بازنویسی HomeScreen نیست؛ فقط ترتیب شناسه‌ها در JSON عوض می‌شود.

### Layoutهای فعلی
- `home_default.json`: هدر → جستجو → بنر → دسته‌بندی → پیشنهاد ویژه → محصولات
- `home_alternate.json`: هدر → جستجو → پیشنهاد ویژه → دسته‌بندی → بنر → محصولات
- `home_offers_first.json`: هدر → جستجو → پیشنهاد ویژه → بنر → دسته‌بندی → محصولات

اگر یک layout اشتباه یا ناقص باشد، HomeScreen مسیر fallback داخلی دارد تا صفحه فروشگاه از کار نیفتد.
