# Flutter Store Client (A + B)

این پوشه نسخهٔ فرانت فروشگاه است که بدون افزودن پکیج جدید به API بک‌اند
Laravel همین پروژه وصل می‌شود. وابستگی‌های استفاده‌شده همان وابستگی‌های قبلی
هستند: Flutter، `http` و `flutter_riverpod`.

## اجرای محلی

1. بک‌اند را در پوشهٔ `../backend` اجرا کنید:

```bash
php artisan serve
```

2. در این پوشه اجرا کنید:

```bash
flutter pub get
flutter run
```

آدرس پیش‌فرض API برابر است با `http://127.0.0.1:8000/api`.

برای Android Emulator:

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000/api
```

برای گوشی واقعی، به‌جای `10.0.2.2` آی‌پی سیستم میزبان در شبکهٔ محلی را بگذارید.
بک‌اند باید با `php artisan serve --host=0.0.0.0 --port=8000` اجرا شود.

## مسیرهای تکمیل‌شده

- Home، بنرهای واقعی، دسته‌بندی‌ها و محصولات واقعی
- جست‌وجو، فیلتر مرتب‌سازی، صفحه‌بندی و جزئیات محصول
- مشخصات پویا، تصاویر و انتخاب Variant
- ورود و ثبت‌نام با Sanctum Bearer Token
- سبد خرید، تغییر تعداد و حذف کالا
- آدرس‌ها، Checkout، کد تخفیف و محاسبهٔ سمت سرور
- ساخت سفارش، Mock Payment و نتیجهٔ پرداخت
- فهرست/جزئیات/لغو سفارش
- علاقه‌مندی‌ها و ثبت/نمایش Reviews
- پروفایل و خروج از حساب

قیمت، تخفیف، موجودی، هزینهٔ ارسال، Coupon و Total نهایی در Flutter محاسبهٔ
مرجع نمی‌شوند و از پاسخ بک‌اند نمایش داده می‌شوند.

## نکتهٔ توکن

برای اینکه پکیج جدیدی نصب نشود، توکن فعلاً در حافظهٔ اجرای برنامه نگه‌داری
می‌شود؛ با بستن کامل برنامه دوباره باید وارد شوید. این موضوع روی API یا امنیت
Sanctum تغییری ایجاد نمی‌کند و بعداً قابل جایگزینی با secure storage است.
